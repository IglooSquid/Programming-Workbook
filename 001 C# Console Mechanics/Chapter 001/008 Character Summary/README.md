### Personal notes

The big thing I learned with this one was to take a single keystroke as an input, and convert it into a single capitalized character. I never actually used the class and race dictionaries that I set up, though with the single character input system that would have been possible -- I'll certainly look into adding that sometime, as it would make the code much cleaner and safer, not having the hardcoded character creation setup in place. I also used a minimal foreach loop to display the adventure log at the end, which was also good practice. Aside from those, essentially everything else was a revision or re-use of concepts from previous exercises.
