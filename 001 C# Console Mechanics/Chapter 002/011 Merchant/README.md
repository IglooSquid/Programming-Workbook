# 011 Merchant

## Goal

Allow the player to buy an item if they have enough gold. **DONE**



## Bonus challenges

1. Add three different items. **DONE**

2. Display the player's remaining gold after each purchase. **DONE**

3. Allow the player to continue shopping until they choose to leave. **DONE**

### Personal notes
I approached this one with a very simplified plan, foregoing any class structures and whatnot and instead just using a list an a dictionary. I got some good practice with dynamically updating the merchant's inventory, and also generating a sequenced key list for the catalogue, like that used in Nethack -- in other words, I made the merchant's inventory organize itself into a list accessible by single keypresses alphabetically from A.
