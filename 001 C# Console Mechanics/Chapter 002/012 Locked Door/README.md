# 012 Locked Door

## Goal

The player reaches a locked door. Depending on what they possess, different outcomes occur. **DONE**



## Bonus challenges

1. Add two different keys. **DONE**

2. Create a door that requires a specific key. **DONE**

3. Add the option to try forcing the door open. **DONE**

### Personal notes
This was, for me, an exercise in updating, checking, and interacting with arrays and dictionaries at runtime. Again I wanted to use a Nethack-like dynamic indexing system where the game automatically orders available options with an alphabet index, and here the challenge was having the option to force the lock open always appear as the last one after the keys, but without leaving any gaps in the list.
