### Personal notes

While I managed to write a pretty snappy basic template for a dialogue step, with reusable, clean and compact formatting, I ran into some trouble with more expansive structures. I ended up succeeding in a relatively functional system of switches and params-powered methods, but as it is this would require a lot of hand-crafting for each dialogue in a proper game. Either way, it was good practice, and I believe I'll be able to refine it as my skills improve.
