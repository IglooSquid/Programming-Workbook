# 018 Camp Rest

## Goal

The player may rest repeatedly until choosing to leave camp. **DONE**



## Bonus challenges

1. Restore a random amount. **DONE**

2. Allow multiple days to pass. **DONE**

3. Consume one food ration each time you rest. **DONE**

### Personal notes
This one was a pretty easy one, as mechanically it didn't really require any new systems, and the whole loop could be performed in very few lines of code. I used it as an opportunity to practice loop logic such as when resting to recover health, making sure healing would happen consistently and the game would recognize the actual amount healed rather than the amount that would have been healed if max health hadn't been reached.
